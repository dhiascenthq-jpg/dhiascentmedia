# Dhiascent Content Planner — 30 Hari

App perancang content Dhiascent: 90 posting (Doa Pagi, Awareness, Closing), versi Threads & WhatsApp, Scan Nama, tracking engagement, export/import.

## Cara pasang di GitHub Pages
1. Upload semua fail dalam folder ini ke repository GitHub (index.html, manifest.webmanifest, sw.js, folder icons).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
3. Tunggu 1–2 minit. Link app: `https://NAMA-AKAUN.github.io/NAMA-REPO/`

## Penting
- Data disimpan dalam browser setiap peranti (tidak disegerak). Export JSON sekurang-kurangnya seminggu sekali.
- Untuk kemas kini app, upload semula index.html yang baru. Data dalam browser tidak terjejas.
